## Misses

### 1. Best Practices 96: `/favicon.ico` 404 (Must fix; fixed, now 100)

- **Audit:** `errors-in-console`: "Failed to load resource: the server responded with a status
  of 404 (Not Found)" for `http://localhost:4310/favicon.ico`.
- **Cause:** `client/index.html` has no `<link rel="icon">` and there is no `client/public/`,
  so the browser asks for `/favicon.ico` and gets a 404. The e2e fixture does not catch it
  because Playwright's Chromium does not request a favicon.
- **Fix:** add `client/public/favicon.svg` (a small mark in the accent colour) and
  `<link rel="icon" href="/favicon.svg" type="image/svg+xml" />` in `client/index.html`.

### 2. SEO 91: robots.txt is invalid (Must fix; fixed with `Allow: /`, now 100)

- **Audit:** `robots-txt`: 14 errors, "Syntax not understood". `/robots.txt` returns 200 with
  `index.html`, because the SPA fallback answers every unknown path with the page.
- **Fix:** add `client/public/robots.txt` with `User-agent: *` and `Allow: /` (or
  `Disallow: /` if the POC should stay out of search engines). Vite copies it to `dist/`.

## Worth doing (within budget)

- **One 97 kB bundle, 60% unused at first load** (`unused-javascript`: 57 KiB). No effect on
  any metric today (no LCP or FCP cost). Look again when routes arrive in M2. Split routes with
  `lazy()` only if first-load JS gets close to 150 kB.
- **Render-blocking CSS** (`render-blocking-insight`): `index-*.css` (2.3 kB), estimated
  140 ms on mobile. LCP is still 0.76 s, so leave it. Vite's default is fine at this size.
- **Request logs carry every request and response header** (pino-http's default
  serializers): about 1.2 kB per line, 385 lines here. Once sessions or auth headers exist they
  would be logged as they are. Before auth lands, add pino `redact` for
  `req.headers.cookie`, `req.headers.authorization` and `res.headers["set-cookie"]`, or
  serialize only method, URL, status and time.
- **Agentic Browsing 50** (a new Lighthouse category, not in the budgets): `llms-txt` and
  `ard-schema` fail. No action for a POC.
