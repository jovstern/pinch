Every status change has a toast (Sonner)

The rule: every async action that changes a recipe's status confirms itself in a toast, and when there is a next step the toast carries it. A status change that happens while the user is elsewhere (a draft becomes ready or fails) shows a toast on whatever page they are on. 11
