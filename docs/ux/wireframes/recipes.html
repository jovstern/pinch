My recipes

Pass 02 · revision 2 (UX only, shadcn greyscale). The library: a search box, tag chips for the quick filters, and a Filters panel for everything else. Filters come from the recipe's own tag facets (design §7: cuisine, meal, diet, flavor, fit), plus time and source.

Phone · 360 · My recipes
Phone · two filters applied
Phone · Filters open (bottom sheet)
  1. Search and Filters on one row: an Input with a search icon, and a Filters button whose badge counts the filters applied. Search covers titles and ingredients ("eggplant").
  2. Tag chips (shadcn ToggleGroup, 40 px tall with a 44 px hit area), scrolling sideways. They are the user's five most-used tags, so the chips match what this household cooks. A chip that is on is filled and shows ✓.
  3. The cards you liked: picture or emoji, title, time and ingredient count. The source shows on the picture (Instagram, YouTube, Facebook); a recipe written by hand has no label.
  4. When filters are on: one line with the count ("4 recipes") and Clear all. Filters live in the URL (/recipes?tags=fit:quick&source=instagram), so Back and a shared link keep them.
  5. Filters panel (shadcn Sheet from the bottom, 85% of the height): Sort, Time, Source, then the five tag facets as chip groups. Every choice updates the count on the button at the bottom, Show 4 recipes, so the user knows before closing whether anything is left. Clear sits beside it.
  6. Write a recipe floats in the same place as on New recipe.
Desktop · 1440 · My recipes, two filters applied
  1. Filters are a panel on the left, always open (260 px): the same groups as the phone sheet, as checkboxes. Each value shows how many recipes it would leave, and values that would leave none are greyed out. No Apply button: the grid updates as you click.
  2. Search and Sort above the grid; the applied filters repeat as removable chips (✕) with Clear all, so you can see what is narrowing the grid without looking left.
  3. A grid of 5 columns at 1440 (4 at 1024, 3 at 768, 2 on a phone).
